About This Research Demonstration

Experimental Framework

This application demonstrates the Prompt Sensitivity Hybrid Mitigation Framework developed across Phases 1–6 of this research project.

  • Baseline Execution: The unmitigated base model (Qwen/Qwen2.5-7B-Instruct in 4-bit NF4) generates completions independently for each prompt variant using greedy decoding.
  • Mitigated Execution: The exact same approved prompt cohort is evaluated via the Phase 6 Evidence-Grounded Router, which applies multi-path verification (Path A Deterministic AST formalization, Path B SQLite FTS5 evidence retrieval, and Path C verification harmonization).

Scientific Transparency & Boundaries

  • Live Inference: All answers and latencies displayed are generated in real-time during your session; they are not pre-cached static summaries.
  • Consistency vs. Correctness: High consistency (answering similarly across paraphrases) does not guarantee factual correctness. In fact, systematic models frequently exhibit unanimous false consensus, which our deterministic tooling is specifically designed to correct.
  • Local Evidence Corpus: Evidence retrieval is backed by a local SQLite FTS5 index curated for verified benchmarks. Open-domain queries outside the index fallback safely to consensus or conservative abstention.
  • Exploratory Sessions: Single-session prompts illustrate behavioral mechanisms but do not replace the formal 450-cluster audited benchmark.

Export & Provenance

Session exports are saved to outputs/session_exports/ in CSV or JSON format. Historical Phase 1–6 evaluation results and benchmark prediction records are never overwritten.
